Free · Run in your browser or install for Windows

Forty-nine PCB engineering calculators in one window.

Impedance, signal integrity, power integrity, RF matching, thermal, EMC, DFM, high-speed digital — all in one self-contained app with Altium-style dark UI, every formula sourced and verified, and a friendly EULA that lets you use it commercially. Try it instantly in your browser or install the Windows desktop build for full 3D openEMS FDTD simulation.
