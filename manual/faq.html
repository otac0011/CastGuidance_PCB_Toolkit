Frequently asked questions

Answers written the way people ask them. If you are looking for a complete description of a tool instead, the tool reference walks each one field by field.

Getting started

What is this toolkit for?

It is a set of 49 design-time calculators for printed circuit boards — impedance, signal integrity, power integrity, RF matching, thermal, EMC, DFM and cost. You type geometry and materials in, you get engineering answers out, and every formula names the standard behind it. It is a calculator set, not a simulator: see what it does not do.

Do I need to install anything?

No. The browser build runs the entire toolkit as WebAssembly in your own tab — nothing to install, no account, nothing uploaded. Install the Windows desktop build only if you want the bundled openEMS 3D field solver.

What is the difference between the browser version and the Windows app?

One thing: the desktop build bundles the openEMS 3D FDTD solver, so the Trace Impedance tool can run a real full-wave extraction. Every other tool, and the analytic impedance estimates, behave identically in both. In the browser the 3D section is visible but disabled with a banner explaining why.

Is it free? Can I use it commercially?

Yes to both. The licence permits commercial use.

Does it upload my design or phone home?

No. There is no account, no telemetry and no upload of your inputs. The browser build computes entirely inside the WebAssembly sandbox in your tab; the only network traffic is fetching the application itself.

How do I find the right tool?

Type into the search box at the top of the left menu, or press Ctrl+P from anywhere. Search matches titles, aliases and tags, so you do not need to know the toolkit's name for a thing — Onderdonk finds Fusing Current, Zdiff finds the Differential Pair Designer, creepage finds Min Conductor Spacing, NSMD finds the BGA Pad Designer.

Where is the Calculate button?

There isn't one. Every tool recalculates as you type. The single exception is Run 3D Simulation on the impedance tool, which is explicit because it takes tens of seconds to minutes.

What do the coloured banners under the outputs mean?

INFO is context worth knowing, WARN means something is outside a normal range or a manufacturability limit has been crossed, and ERROR means the inputs describe something that cannot be built. A tool never silently clamps a bad input and shows you a plausible number instead.

Can I save my work?

Only from the two tools that produce a document: the Design Wizard exports its report as HTML or Markdown, and the LC Matching Ladder exports Touchstone, HTML or TXT. There is no project file and no document model — tool inputs reset to defaults each time you open a tool.

Can I open my Gerber, Altium or KiCad files?

No. There is no CAD import of any kind — no Gerber, ODB++, IPC-2581, netlist, project file, stackup file, IBIS model or Touchstone import. Every input is typed. Get the number from your CAD tool and enter it.

Why did my inputs reset when I came back to a tool?

Because there is no document model — each tool opens at its defaults. If you need to keep a result, export it (Wizard, LC Ladder) or screenshot it.

Can I run it on macOS or Linux?

Use the browser build, which runs anywhere with a modern browser. The packaged desktop installer with the bundled solver is Windows-only.

What do I do if a number looks wrong?

Check the citations in the tool first — half of apparent disagreements are two different standards, both correctly implemented (IPC-2152 versus IPC-2221 for trace current is the classic). Then check you have not given a tool bulk Dk where it asked for ε_eff. If it still looks wrong, report the tool, every input, what you got, what you expected and where your expectation came from.

Units and reading results

Is a "mil" a millimetre?

No — a mil is one thousandth of an inch, exactly 0.0254 mm or 25.4 µm. It is the dominant unit in North American PCB fabrication, so most fields default to it. Package drawings from semiconductor vendors are metric.

How do I switch between mm and mils?

The BGA Pad Designer has a Units dropdown at the top that governs every input and output on the page at once. Other tools show most length outputs in both units side by side, e.g. 9.45 mil (0.240 mm). Switching units converts the display; it never reinterprets what you typed.

What is the difference between Dk, εr and ε_eff?

Dk (also written εr) is the bulk permittivity of the laminate from its datasheet. ε_eff is what a microstrip trace actually sees — part of the field is in air, so ε_eff lands between 1 and Dk. For stripline, the trace is surrounded by laminate so ε_eff = Dk. Giving a tool bulk Dk where it asked for ε_eff is the single most common input error in the toolkit, and it produces a plausible-looking wrong answer.

How do I get ε_eff?

Use the Er Effective tool — it takes width, height, bulk εr and frequency. A rough starting point is ε_eff ≈ 0.65 × Dk for surface microstrip, but the real value depends heavily on the width-to-height ratio.

How thick is 1 oz copper?

1.378 mil, about 35 µm. Copper is sold by weight per square foot, not by thickness: 0.5 oz ≈ 17.5 µm, 1 oz ≈ 35 µm, 2 oz ≈ 70 µm. The toolkit uses the exact IPC-2152 value of 1.378 mil rather than the rounded 1.4 mil.

Should I enter base copper or finished copper thickness?

Finished, unless the field says otherwise. Plating adds roughly 1 oz to outer layers, so a board ordered as "1 oz outer" typically finishes near 1.4–2 oz. Inner layers are not plated, so base equals finished there.

What is Df, and is it the same as tan δ?

Yes, they are the same thing: the dielectric loss tangent, the fraction of energy the laminate absorbs per cycle. Typical values are 0.02 for generic FR-4, 0.005 mid-loss, 0.002 for Megtron-class, 0.0009 for PTFE. Unlike Dk, Df generally rises with frequency.

My driver has a rise time but the tool wants a frequency. What do I use?

Use the knee frequency from Bandwidth & Max Length: BW = 0.35 / t_r per IPC-2251, or BW = 0.5 / t_r per Howard Johnson if you want to be conservative. The edge rate is what matters, not the clock rate — a 10 MHz clock with a 200 ps edge has a knee near 1.75 GHz.

What is the Nyquist frequency of my link?

Half the symbol rate. A 16 Gbps NRZ link has an 8 GHz Nyquist. For PAM4 the symbol rate is half the bit rate, so a 32 Gbps PAM4 link also has an 8 GHz Nyquist. Insertion-loss budgets are almost always quoted at Nyquist.

Does ΔT mean an absolute temperature?

No — ΔT is always a rise above ambient. ΔT = 10 °C with T_a = 25 °C means the copper reaches 35 °C.

What do the min / typical / max columns mean?

They are a design window, not a prediction of what your fab will deliver. The middle column is the target; the outer columns bound what is acceptable. Where a geometric limit is tighter than the standard's window, the reported max is clamped to the real limit and a diagnostic says so.

Stackup and materials

How do I choose a laminate?

Open Material Comparison, sort by whichever property is driving your decision (Df for loss, Tg for assembly, z-CTE for via reliability), tick the candidates and switch on Compare selected only. Then move the Dk and Df of your shortlist to your actual design frequency with the Dielectric Dk/Df tool before comparing them.

Is FR-4 good enough for my design?

Usually, up to a few GHz and a few gigabits. Generic FR-4 has Df around 0.02 and poorly controlled Dk, so it starts to hurt when dielectric loss dominates your budget or when Dk variation moves your impedance. Run the Insertion Loss Budget with FR-4 numbers and see whether the dielectric term alone blows your budget — that is the honest test.

Why is Dk quoted at 10 GHz when I'm designing at 2 GHz?

Because that is where the manufacturer measured it. Dk falls slowly with frequency, so a 10 GHz number is slightly low for a 2 GHz design. Use the Dielectric Dk/Df tool to move it; between 1 and 10 GHz a typical FR-4 changes Dk by 2–4 %, which is roughly 1 Ω on a 50 Ω trace.

Can I compare two materials whose datasheets are at different frequencies?

Not directly — you will get the wrong answer. A material specified at 28 GHz looks worse than one specified at 10 GHz even when it is better. Move both to a common frequency first. The Spec f column in Material Comparison exists precisely so you notice this.

What is Tg and how much do I need?

Glass transition temperature — above it the resin softens and z-axis expansion accelerates sharply. Lead-free assembly wants Tg ≥ 150 °C; thick boards or multiple reflow cycles want 170 °C or better.

What is z-CTE and why should I care?

Expansion through the board's thickness, in ppm/°C. It is what cracks plated via barrels during thermal cycling, so for via reliability it matters far more than in-plane CTE. Sort on it in Material Comparison when reliability is the driver.

My board came back warped. What happened?

Almost certainly copper imbalance. Boards warp because copper and resin shrink differently as the laminate cools from lamination temperature, so an asymmetric stackup curls. Put your layer coverages into Stackup Symmetry & Bow and look at the symmetry score.

How do I fix a bad symmetry score?

Add copper thieving — non-functional copper pours — to the sparse layers to balance coverage, or restack so heavy planes sit symmetrically about the centreline. Both are free at design time and expensive after the first article comes back bowed.

How much bow is allowed?

IPC-6012E's limit for surface-mount boards is 0.75 % of the diagonal. On a 200 mm board that is 1.5 mm, which sounds generous until you try to place a 0.5 mm-pitch BGA on it. The tool computes the absolute limit for your board size.

How many layers do I need?

Two things usually decide it: how many signal layers the BGA breakout needs, and whether every signal layer has an adjacent reference plane. Use BGA Escape Routing for the first, then start the Design Wizard for a whole-stackup recommendation.

Impedance and the 3D solver

How do I get a 50 Ω trace?

Open Trace Impedance, pick your topology, enter the material and the dielectric height to the reference plane, then adjust the trace width until the analytic estimates read 50 Ω. The dielectric height matters more than anything else — if 50 Ω needs an unmanufacturably wide or narrow trace, change the layer spacing, not the width.

There are four impedance numbers. Which one do I use?

When they agree, any of them. Hammerstad-Jensen is the usual choice for microstrip and Cohn for stripline. What matters more than picking one is the spread between them: close agreement means your geometry is well inside their validated range.

Why do the four analytic estimates disagree with each other?

Because each is an empirical fit with its own validated range of W/H, T/H and εr, and your geometry has fallen outside one or more of them. Treat divergence as a warning rather than a nuisance — that is exactly when to run the 3D solver or change the geometry until they converge.

When should I run the 3D simulation?

When the analytic estimates disagree, when your copper is unusually thick, when you have a tight coplanar gap, or as a final confirmation once the geometry is settled. Converge with the instant analytic numbers first — running FDTD on every trial width wastes minutes for nothing.

Why is the 3D simulation greyed out?

You are in the browser build. The solver is a native compiled engine driven through a Python sidecar, and neither runs in a browser sandbox. Install the Windows desktop build if you need it; everything else is identical.

How long does a 3D simulation take?

Tens of seconds at coarse mesh settings, up to several minutes at fine ones. The Sim quality dropdown is the trade-off, and the tool reports the mesh resolution it actually used so you can judge whether it was fine enough for your feature sizes.

Which topology should I pick?

Match your cross-section: Standard Microstrip for a surface trace over a plane, Embedded Microstrip if it is under soldermask or a thin dielectric, Stripline for a buried trace between two planes, CPWG when the trace has coplanar ground either side, and the differential variants for pairs. The diagram changes with the selection so you can confirm visually.

What is CPWG and when would I use it?

Coplanar waveguide with ground — a trace with ground pours on both sides at the same layer, usually stitched with vias. It gives tighter field confinement and better isolation than plain microstrip, at the cost of board area and a lot of stitching vias. It is common in RF front ends and rare in digital designs.

My impedance is too low. What do I change?

In order of effect: increase the dielectric height to the reference plane, narrow the trace, or move to a lower-Dk material. Height is by far the strongest lever — if a 50 Ω trace on your stackup comes out at 4 mil wide, the fix is a thicker dielectric, not a heroic etch tolerance.

Does copper thickness affect impedance?

Yes, though less than width or height. Thicker copper lowers impedance slightly because the trace has more surface area coupling to the plane, and it matters more on thin dielectrics. Enter finished copper, not base.

Why is my stripline slower than my microstrip?

Because a stripline is buried in laminate on all sides, so ε_eff equals the bulk Dk. A microstrip has part of its field in air, which pulls ε_eff down — and propagation delay goes as √ε_eff. On Dk 4.2 material a stripline is roughly 20 % slower than a surface microstrip.

What is the difference between embedded microstrip and stripline?

Embedded microstrip has a reference plane on one side and dielectric (or soldermask) covering the trace on the other. Stripline has planes on both sides. The difference is not cosmetic — embedded microstrip still has an asymmetric field, so ε_eff sits between the microstrip and stripline values.

Can openEMS simulate my whole board?

No. The bundled solver extracts characteristic impedance for the transmission-line cross-sections the tool offers. It does not import a layout, does not simulate a board, a package or a connector, and does not do time-domain channel simulation.

The 3D solver failed to start. What now?

The usual causes are an antivirus product quarantining the bundled native engine, or an installation that was moved rather than reinstalled so relative paths no longer resolve. Reinstalling in place fixes both. If you only need impedance numbers, the analytic path needs none of this and always works.

Differential pairs

What is Zdiff and why isn't it just 2 × Z₀?

Z_diff is the impedance seen across the pair, and it is less than 2 × Z₀ because the two traces couple to each other. The coupling lowers each trace's odd-mode impedance, and Z_diff = 2 × Z_odd. The tighter the coupling, the further Z_diff falls below 2 × Z₀.

How do I design a 100 Ω differential pair?

Open the Differential Pair Designer, set the target to 100 Ω with your tolerance, enter your stackup, and set W and S sweep ranges generously. The green band on the 3D surface shows every combination that hits the target; take the recommended point or pick your own from inside the band.

The green band is empty. What now?

No (W, S) combination in your swept range hits the target. Widen the sweep ranges first — often the answer is just outside. If it is still empty, the stackup is the problem: for a 100 Ω pair the usual fix is a thinner dielectric to the reference plane, not a different trace width.

Should I use tight or loose coupling?

Loose coupling for most digital work. Tight coupling gives better common-mode rejection and takes less width, but it makes Z_diff extremely sensitive to spacing tolerance and to anything that disturbs the gap — a via, a component pad, a bend. With loose coupling each trace is nearly independent, so manufacturing variation moves the impedance much less.

Does the gap between the pair have to be constant?

Where it can be, yes — Z_diff depends on it. But a short discontinuity (going around a via, entering a connector footprint) is usually harmless if it is much shorter than a wavelength at your edge rate. Length-match after the discontinuity, and keep the disturbance short rather than gradual.

What differential impedance does my interface need?

90 Ω for USB 2.0, 100 Ω for Ethernet, PCIe Gen3+ and HDMI, 120 Ω for CAN-FD, and 85 Ω for some DDR4 implementations. Always check the specification you are actually building to — a few interfaces allow a range.

Which W and S should I pick out of the green band?

Prefer the wider-trace, wider-spacing end. Both are easier to fabricate, and both make the impedance less sensitive to etch variation. That is exactly what the tool's recommendation optimises for, which is why it breaks ties toward wider geometry.

Can it do stripline differential pairs?

The Differential Pair Designer's surface sweep covers edge-coupled microstrip and edge-coupled embedded microstrip. For stripline pairs use the Trace Impedance tool, which offers edge-coupled and broadside-coupled differential stripline — you just do not get the 2D manufacturability sweep there.

Vias and microvias

How much inductance does a via have?

Roughly 1 nH per millimetre of barrel length as an order of magnitude, but use Via Properties for a real number — it depends on the barrel length, the diameter and the return path. Length dominates.

How do I reduce via inductance?

Shorten the barrel — that is the dominant term. Then put the return via as close as possible, because the loop area between signal and return is what the inductance really measures. Increasing the drill diameter helps very little; doubling it buys you a small fraction of what halving the length does.

What aspect ratio can my fab drill?

8:1 is universally standard, 10:1 is a small adder, 12:1 costs more, and 14:1 is about the limit of plating throwing power. Above that most fabs quote rather than list a price. Aspect ratio is board thickness ÷ finished hole diameter — check it in Via Properties.

What is a microvia and when do I need one?

A laser-drilled via that spans a single dielectric layer, typically 75–100 µm across. You need them when a fine-pitch BGA leaves no surface routing channel — below about 0.5 mm pitch, microvia or via-in-pad escape stops being an optimisation and becomes the only way out.

Should I stack or stagger microvias?

Stagger, once you go beyond two levels. Stacked microvias concentrate thermal stress at exactly the interface that fails, and IPC-6012ES often requires extra qualification testing for 3-high stacks. Staggered is also the cheaper option.

What is a weak microvia interface?

WMI is an incomplete metallurgical bond between the microvia's plated copper and the target pad. It survives electrical test and then opens during thermal cycling — or even during the first reflow. It is the dominant microvia failure mode, which is why the Microvia Analyzer raises it as an advisory rather than burying it.

Why does return-via spacing matter so much for a microvia?

Because inductance is set by the loop area between the signal via and wherever the return current gets back to the other plane. A stitching via 0.5 mm away gives a tiny loop; one 5 mm away gives a loop big enough to throw away the microvia's whole advantage. It moves the answer more than any other input on that page.

What annular ring do I need?

5 mil external is a common design default and 2 mil is the IPC Class 2 production minimum after drill registration. Set your target in Padstack Calculator and check that the pad still fits between adjacent holes at your pitch.

What is an antipad and how big should it be?

The clearance hole in the plane layers a via passes through. Bigger antipads lower the via's capacitance (good for high speed) but eat plane copper and push return current further around (bad for inductance and for plane integrity). Start from the tool's default and only enlarge it if the via capacitance is actually a problem in your budget.

Do I need thermal relief on plane connections?

For hand-soldered through-hole parts, yes — a direct connection to a plane sinks so much heat that a good joint is difficult. For SMT and for current-carrying connections, prefer a direct connection: thermal spokes add resistance and inductance for no benefit once a reflow oven is doing the heating.

BGA pads

What size pad should I use for a BGA ball?

Open the BGA Pad Designer, enter the ball diameter and pitch from the package drawing, and read the typical NSMD land. The IPC-7351B rule is a percentage reduction from the nominal ball diameter: ×0.85 for balls up to 0.20 mm, ×0.80 from there to 0.50 mm, and ×0.75 above that.

NSMD or SMD — which should I use?

NSMD is IPC-7095's default recommendation because the solder anchors the land's sidewall as well as its face, giving a stronger joint. SMD becomes attractive at very fine pitch, when the etched land would be too small to hold registration reliably. In practice the decision is usually made by your fab's solder-mask registration, not by reliability theory — enter the number they quote you and see whether the SMD minimum still leaves a workable copper gap.

What is solder-mask registration and where do I get the number?

It is how far the solder mask can shift relative to the copper, quoted per side. Ask your fabricator — it is a standard capability question. 1 mil is a reasonable modern default, 2 mil is safe for a low-cost fab, and shops using LDI will quote 25 µm or better.

What is the smallest pad I can use?

For SMD, the mask opening plus twice the registration tolerance — that is the green headline number on the page. Below it the mask can slip off the copper edge and you get a partially mask-defined joint whose diameter nobody controls. Type your fab's registration figure in and the number recomputes immediately.

Why doesn't the pitch change my pad size?

Because IPC-7351B keys the land reduction on ball diameter alone. Pitch does not set the target — it sets the ceilings: how much copper fits before adjacent lands violate your etch spacing, and how much mask opening fits before the dam between openings gets too thin. The tool reports both ceilings and clamps the maximum to them.

What is a solder-mask dam and how thin can it be?

The web of mask between two adjacent openings. 3 mil is the usual fab floor; below roughly 75 µm the dam washes off during develop and stops doing its job, which is preventing solder bridging. The tool computes the dam at your chosen geometry so you can compare it to your fab's minimum.

My vendor's recommended footprint differs from the tool. Who is right?

Both, usually. Vendors sometimes deviate from IPC deliberately to tune board-level reliability for their specific package — one FPGA vendor sizes a land to match the package's own pad rather than to IPC, putting it slightly outside the IPC band. Enter the package-side pad diameter and the tool will compare it against the IPC target and flag the difference. When a datasheet gives you a recommended footprint, it usually wins.

Which ball diameter do I enter — min, typical or max?

Typical. The package drawing's "b" dimension has min/typ/max columns and the IPC land size is derived from the nominal, so use the middle one.

What stencil thickness should I use for a 0.5 mm pitch BGA?

Check the Max stencil foil output — it tells you the thickest foil that still clears the IPC-7525B 0.66 area ratio for your aperture. For a 0.30 mm ball with a 0.24 mm land that comes out near 3.6 mil, which is why a general-purpose 4 mil foil fails on fine-pitch BGAs.

Why is my area ratio failing?

The aperture is too small for the foil thickness — area ratio is D / (4T) for a circle and IPC-7525B wants ≥ 0.66. Thin the foil (the tool tells you to what), enlarge the aperture, or use a nano-coated or electroformed stencil that releases better. On a mixed board a step stencil — locally thinned over the fine-pitch area — is the standard answer.

What is collapsed standoff and should I trust it?

It is the predicted joint height after reflow, from a constant-volume truncated-sphere model: the ball's solder volume is conserved and the joint becomes a sphere truncated by the two wetting planes. It is a geometry estimate, not a reflow simulation — it ignores surface tension, package weight and printed paste. Use it comparatively, to see how standoff falls as the land grows, not as an absolute prediction.

Why do NSMD and SMD show the same standoff?

Because by default they are sized to the same joint diameter, and standoff depends on the wetted diameter. The real difference between them is the wetted area — NSMD adds the land's copper sidewall to the joint, which is what the "NSMD anchor area" figure quantifies.

Can I route between 0.5 mm pitch BGA balls?

Barely, and usually not. With a 0.24 mm land and 4 mil clearance the surface channel is a few mils wide — not enough for a trace at any normal design rule. Check the Escape channel output, and if it is at or near zero plan on via-in-pad or HDI microvia escape. The BGA Escape Routing tool turns that into a layer count.

Do I need via-in-pad for my BGA?

If the escape channel is zero, yes. Via-in-pad requires the vias to be filled and capped (POFV/VIPPO) so solder does not wick down the barrel — which is free at some Chinese fabs on 6+ layers and around +40 % at US fabs. Check the tradeoff in the PCB Cost Estimator.

Does the BGA Pad Designer know about specific parts?

No, deliberately. The preset dropdown lists standard pitch and ball geometries only — it is a shortcut for typing two numbers, not a parts library. Read the "b" typical dimension off your own package drawing and enter it.

Channel loss and signal integrity

How much loss can my channel afford?

The specification tells you — and if you pick a protocol preset in Via Stub Impact the budget is filled in for you along with the FEC margin. Then total your actual channel with the Insertion Loss Budget and compare.

Where is my loss actually coming from?

Read the per-component breakdown in the Insertion Loss Budget: dielectric, conductor, via stub and connector are reported separately, along with α_d and α_c in dB/inch. That breakdown is the whole point of the tool — spending money on the wrong term is the most common channel-budget mistake.

Will a better laminate fix my loss problem?

Only if the dielectric term dominates your breakdown. If conductor loss is the bigger number, a low-Df laminate changes almost nothing and what you actually need is wider traces and smoother copper foil. Look at the breakdown before you buy Megtron.

Why does dielectric loss matter more at higher data rates?

Because dielectric loss scales roughly linearly with frequency while conductor loss scales with the square root of frequency. So as you go up in rate the dielectric term grows faster and eventually dominates — which is why the industry moved to low-Df laminates rather than just thicker copper.

What copper roughness should I specify?

STD foil has Rz around 5.7 µm, RTF 4.4 µm, VLP 3.5 µm and HVLP 2.0 µm. Below about 10 Gbps standard foil is fine; at 25 Gbps and above, VLP or HVLP is normal. Put your candidates into Conductor Loss and read the multiplier — roughness alone can be a 30–60 % loss difference on identical resin.

What is Rz and where do I find it?

Rz is the ten-point mean roughness of the copper foil, quoted in µm on the laminate or foil datasheet. The Cannonball-Huray model in the toolkit takes Rz directly, which is why it is the default — the older models need a surface-ratio parameter you have to fit rather than look up.

Why does copper roughness matter so much at high frequency?

Because skin depth shrinks with frequency until it is smaller than the tooth on the foil. At 10 GHz the skin depth in copper is about 0.66 µm — less than the roughness of standard foil — so the current is forced to follow a longer, bumpier path. Below a few GHz the effect is negligible.

What is a via stub and why does it matter?

The unused length of a via barrel below (or above) the layer your signal actually uses. It is an open-circuited transmission-line stub, and at the frequency where it is a quarter wavelength long it presents a short at the signal layer and drops a deep notch in the channel response.

Do I need to back-drill?

Check the recommendation badge in Via Stub Impact — it grades from OK through Watch to Back-drill recommended and required. The underlying question is where the quarter-wave resonance sits relative to your Nyquist frequency.

How do I know if the stub resonance will hurt me?

Compare the quarter-wave resonance frequency to Nyquist. Above 2 × Nyquist the stub is usually harmless; as resonance approaches Nyquist the notch lands inside your signal band and the insertion-loss adder climbs sharply. Both numbers are in the outputs and both markers are on the S21 plot.

What does the notch in the S21 plot mean?

That is the quarter-wave stub resonance — the dotted-red marker. At that frequency the stub shorts the signal layer and energy stops getting through. The dashed-blue marker is your Nyquist; you want a lot of distance between the two.

What does back-drilling cost?

Roughly +17 % at a Chinese fab and +30 % at a US fab. Model it with the rest of your feature set in the PCB Cost Estimator — it is often cheaper than the laminate upgrade you were considering instead.

Can I avoid stubs without back-drilling?

Yes: route the high-speed signal on the layer pair that leaves the shortest unused barrel, use blind or buried vias so there is no stub at all, or use a thinner board. Choosing the right layer is free and is the first thing to try.

How much jitter can I afford?

Put your Dj and Rj into Jitter Budget with your baud rate and target BER; it reports Tj peak-to-peak and Tj as a percentage of the unit interval. Compare that against the eye budget in your specification.

Should I attack Dj or Rj?

Rj, almost always. Deterministic jitter is bounded — halving it improves Tj by that amount once. Random jitter is multiplied by the Q factor, so at 1e-12 each picosecond of Rj costs you 12.7 ps of Tj. If your budget is blown, look at the reference clock and the PLL before you look at the routing.

What Q factor does my BER imply?

12.7 at 1e-12 and 14.07 at 1e-15 — the tool reports the exact value it used. That factor is the number of standard deviations of Gaussian jitter you have to allow for, which is why demanding a lower error rate costs you eye.

How do I length-match a DDR bus?

Use DDR Length Matching: pick your standard to load the JEDEC tolerance, then paste in the as-routed length of every DQ, DM, DQS, ADDR, CMD and CK signal. It reports each signal's deviation from its group reference and flags anything out of spec.

Do all my DDR byte lanes need to match each other?

No — and trying to is a waste of routing area. Each byte lane is matched to its own DQS strobe, and the address/command group is matched to CK. Lane-to-lane skew is absorbed by write and read levelling during training.

What about skew inside the DQS pair?

Match it tightly, ideally at the package pin. Intra-pair skew on the differential strobe is the one error training cannot compensate for, so it matters more than inter-signal skew within the lane.

Can the toolkit produce an eye diagram?

No. The eye-closure numbers in the Via Stub tool are analytic estimates from the stub's frequency response — they are not a simulated eye. There is no time-domain or statistical channel simulation, no impulse response, no bathtub curve and no IBIS-AMI link training anywhere in the toolkit.

Power integrity

What target impedance does my rail need?

Z_target = allowed ripple ÷ transient current step. Put the rail voltage, allowed ripple and transient into PDN Target & Plane Cap and it does the arithmetic — a 1.0 V rail allowing 3 % ripple with a 10 A step needs 3 mΩ, flat, out to the edge rate.

What is the transient fraction and why does it matter?

It is the proportion of maximum current that is the actual step, and it matters because the PDN only sees the step. A 20 A rail with a 20 % transient is a 4 A step and a five-times easier target than a full 20 A step would be. Guessing 100 % here will make you over-design badly.

How many decoupling capacitors do I need?

Enough to hold the impedance below target across the whole frequency band — which is a curve, not a count. Build the bank in Cap Bank Analyzer, overlay your target line, and add parts until the worst-case |Z| sits under it.

Should I use lots of different capacitor values?

No — that is outdated advice. Different values in parallel create anti-resonance peaks between their self-resonant frequencies, and a third value added to "cover the gap" often creates two peaks instead of one. The modern approach is fewer distinct values and more parts of each.

What is anti-resonance?

Between two capacitors' self-resonant frequencies, one is already inductive while the other is still capacitive. Together they form a parallel LC tank, which produces an impedance peak — often higher than either capacitor alone. The Cap Bank Analyzer counts and locates these peaks for you.

What is the NISM flatness ratio?

Z_max ÷ Z_min across the sweep — a measure of how flat the PDN impedance is. A flat PDN is a well-behaved PDN, because a peak at any frequency is where a transient with that spectral content will produce ripple. Minimising the ratio is usually a better goal than minimising the average impedance.

My 10 µF capacitor is only giving 4 µF. Why?

DC bias. Class II ceramics (X5R, X7R, Y5V) lose capacitance under applied voltage, and the datasheet value is measured at 0 V. Run the part through MLCC DC-Bias Derating — a "10 µF 10 V X7R 0603" commonly delivers 4 µF at 5 V bias.

What voltage rating should I pick for an MLCC?

Enough headroom that you stay on the flat part of the derating curve. A 10 V part at 10 % bias keeps around 95 % of its value; a 6.3 V part at 80 % bias can drop to 20–30 %. Over-rating is cheaper than adding parts to make up the shortfall.

Does capacitor package size matter?

Yes, a lot. A larger case size of the same value and voltage derates less under bias because the dielectric is thicker. It also usually has lower ESL. The trade is board area — which is why the answer is rarely "the smallest part that fits".

Does C0G/NP0 derate under bias?

No — Class I ceramics are stable with both voltage and temperature. The catch is that they are only available at small values, so they are used for RF and timing rather than bulk decoupling.

Where should I put the decoupling via?

As close to the capacitor pad as the fab allows, ideally in or immediately beside the pad. What matters is the loop area from the pad through the via to the plane and back, and that loop is what Mounting Inductance computes.

Does mounting inductance really matter that much?

Above roughly 100 MHz it dominates the capacitor entirely. An 0402 with 0.6 nH of its own ESL, mounted with two through-board vias, easily picks up 2 nH of mounting inductance — tripling the high-frequency impedance the rail actually sees. Chasing a lower-ESL part while ignoring the mounting is wasted money.

What is the most effective way to lower mounting inductance?

In order: put the plane pair closer to the surface so the vias are shorter, put the vias in or beside the pads so the loop is small, use more vias in parallel, and only then look for a lower-ESL capacitor. The first two are free.

How do I size a buck converter inductor?

Enter V_in, V_out, load current, switching frequency and your target ripple into Buck / Boost Inductor. It returns duty cycle, the required inductance, ripple current, and the peak and RMS currents you need for part selection.

What inductor ripple should I target?

25–40 % of the output current is the usual compromise. Less ripple needs a physically bigger inductor; more ripple needs a bigger output capacitor and costs efficiency in core loss.

What saturation current rating do I need?

Size against the peak current, not the average or the RMS. A converter that saturates its inductor on a load step does not degrade gracefully — the inductance collapses, current spikes, and the switch usually fails. The tool reports peak and RMS separately for exactly this reason.

RF and impedance matching

How do I match a complex load?

Use the LC Matching Ladder — it takes complex Zs and Zl as R + jX directly. The quarter-wave transformer tool only handles real impedances; if you want to use it, cancel the reactance first with a series element.

Series-first or shunt-first?

The shunt element belongs across the higher-resistance side. Series-first puts the shunt toward the load (use it when the load is above your reference resistance); shunt-first puts it on the source side (when the load is below). The tool raises an advisory if your choice is the opposite of what the terminations call for.

How many legs should my ladder have?

Start with the fewest that meet your |S11| target. One leg is an L-network and is fully determined. More legs buy bandwidth and lower node Q, at the cost of parts, board area and insertion loss. Add legs when a 2-leg solution is too narrow or too high-Q, not by default.

What is the component-value spread slider for?

For 3 or more legs there is a whole family of solutions rather than one answer. The slider sweeps that family from the smallest L/C values that still match to the largest, so you can pick the one that suits your parts inventory and layout.

Why are some slider positions missing?

Because they do not meet your pass |S11| target in the selected mode, so they have been dropped. Every position you can select is a design that actually works — the slider never offers you a solution that fails.

Why is the spread slider disabled?

You have a 1- or 2-element match, which is fully determined — there is exactly one answer, so there is no family to sweep. The slider becomes active at 3 legs.

What is node Q and why should I care?

It is how sharply tuned each node of the network is, and it predicts how touchy the match will be. A high-Q node means a narrow match that moves when a component is 5 % off or a nearby copper pour changes the pad capacitance. If the solver offers a lower-Q solution at the same |S11|, take it.

Which of the three calculation modes should I use?

Purchasable re-solved for anything you are actually going to build. Raw ideal shows the mathematics, ideal-snapped shows what happens if you just round to stock values, and purchasable re-solved solves the values so the real network — with ESL, pad capacitance, solder inductance and ESR — meets the target at f₀.

Why does the tool refuse sub-picofarad capacitors?

Because you cannot buy or place them reliably, and at those values the pad and trace capacitance swamps the part. Values are bounded to a realistic RF window (roughly 1–100 pF for C0G capacitors and 0.8–120 nH for 0402 inductors) even in the theoretical mode.

Can I use different package sizes for the capacitors and inductors?

Yes — they are chosen independently, and an 0201 capacitor with an 0402 inductor is a normal combination. Each type's bounds and parasitics are tracked from its own package.

My match works in the tool but not on the bench. What did I miss?

Three usual suspects. You used the ideal or ideal-snapped mode instead of purchasable re-solved, so the parasitics were never in the answer. Your node Q is high and a 5 % component tolerance moved the match. Or your assumed load impedance is not what the load actually presents at that frequency — measure it rather than taking it from a datasheet.

Can the LC ladder match to a measured .s2p file?

No — there is no Touchstone import. The ladder writes .s2p files but cannot read one. If you have a measured impedance, read R and X at your frequency of interest off the VNA and type them into the Zs / Zl fields.

Is there a Smith chart?

Not yet. The Smith chart view is planned for a future update. You do get the S11-versus-frequency plot with the target line. The Monte Carlo tolerance yield is in the current build, on the ladder's Real-part build card.

LC ladder or quarter-wave transformer?

At low GHz on a small board, the lumped LC ladder — a quarter-wave section at 2.4 GHz on FR-4 is about 17 mm, so a 4-section transformer is nearly 70 mm of trace. Above roughly 5–10 GHz the distributed transformer wins because lumped components stop behaving like lumped components.

How many quarter-wave sections should I use?

Each extra section roughly doubles the usable bandwidth and adds a quarter wavelength of board. Start with the fewest that meet your VSWR criterion across the band you need, which the tool reports as a fractional bandwidth.

Binomial or Chebyshev?

Binomial for a clean, monotonic in-band response; Chebyshev when you need wider bandwidth and can tolerate equal-ripple inside the band. If your specification gives a single worst-case VSWR across a band, Chebyshev usually gets you there with fewer sections.

Pi-pad or T-pad?

Electrically they are equivalent, so choose on layout and on component values. At high attenuation the Pi's series resistor becomes very large and the T's shunt resistor becomes very small — pick whichever puts your values in a comfortable range.

Can I fix a bad match with an attenuator?

Often, yes — it is the cheapest fix available. 6 dB of pad improves a 3:1 VSWR to about 1.3:1, at the cost of 6 dB of signal. On a test port or a driver output with headroom to spare, that is usually a good trade.

Thermal, EMC and manufacturing

How hot will my part get?

Enter ambient, dissipated power and θJA into Thermal Management for the no-heatsink case; add θJC, θCS and θSA for the heatsinked one. It reports junction temperature and the margin to Tj_max for both.

Is θJA from the datasheet trustworthy?

Only as a comparison between packages. θJA is measured on the JEDEC test board — usually 2s2p in still air — not on your board. When the margin is tight, use θJC plus your own board's spreading path instead.

How many thermal vias do I need under a QFN?

Fewer than you think. Put your geometry into Thermal Via Array and watch the two terms it reports: once the via array's resistance drops below the plane's spreading resistance, adding vias changes nothing.

Why don't more thermal vias help?

Because heat has to leave the plane once it gets there. When spreading resistance dominates, the fix is more copper area or a thicker plane, not more holes. The tool reports the spreading fraction so you can see which term is in control.

Does solder voiding under the pad matter?

Yes — a 5–15 % void fraction is typical for a well-designed paste aperture and the tool includes it in the array resistance. Larger voids come from a single big aperture; splitting the exposed-pad aperture into a window-pane pattern is the standard fix.

Will my board pass radiated emissions?

This toolkit cannot tell you that, and no first-order calculator can. Radiated Emissions models an electrically-small loop in free space; real boards emit mostly from cables and enclosure resonances. Use it to find which harmonic is your problem and to compare two layouts, not to predict a pass.

Why does loop area matter so much for EMI?

Because emission scales with loop area and with the square of frequency. Halving the loop area buys 6 dB, and the frequency term means the harmonics of a fast edge dominate. That is the quantitative argument for tight return paths — it is not a rule of thumb, it is a squared term.

What does a 6-layer board cost?

Put the specification into the PCB Cost Estimator and compare regions. Note that 6 layers is often a sweet spot at Chinese proto fabs because of how their promotional pricing is structured — the tool models that rather than assuming a smooth curve.

Why is my cost estimate different from the fab's quote?

The estimator is engineering-grade, typically within ±25 %. It models published price structures rather than any particular fab's live pricing, and it cannot know about promotions, panel utilisation on your specific board outline, or your account's negotiated rates. Always verify on the fab's quote page before purchasing.

Which features are free at Chinese fabs but expensive in the US?

Controlled impedance, ENIG on 6+ layers, POFV/VIPPO via fill, non-green soldermask and both-sides silkscreen are all commonly free at Chinese proto fabs and carry real adders at US fabs. Layer count, exotic laminate, tight drill and HDI cost real money everywhere.

Do I need controlled impedance?

If you have any interface with a specified impedance — USB, Ethernet, PCIe, HDMI, DDR, RF — yes. It is free at Chinese multilayer fabs at standard tolerance, which makes the decision easy; tightening to ±5 % costs extra and ±3 % is quote-only.

What is POFV / VIPPO?

Plated-over filled via / via-in-pad plated over: the via is filled with resin and plated flat so a component pad can sit directly on it. You need it for via-in-pad BGA escape, otherwise solder wicks down the barrel during reflow.

Will paste release from my stencil aperture?

Check the area ratio in Paste Aperture — it must be ≥ 0.66 per IPC-7525B, with aspect ratio ≥ 1.5 for long thin apertures. Below that, paste sticks to the aperture walls instead of transferring to the board.

What is a step stencil?

A stencil that is locally thinner over part of the board — typically over fine-pitch parts — so those apertures clear the area-ratio floor while connectors and large passives still get enough paste from the thicker regions. It is the standard answer for a mixed-technology board.

What is the difference between IPC Class 2 and Class 3?

Class 2 is the general commercial standard; Class 3 adds tighter annular ring, plating thickness and defect criteria for high-reliability products. Class 3 costs about +20 % at US fabs and is effectively unavailable at low-cost Chinese proto fabs — the estimator warns you about that combination.

Getting started on a new board

Where do I even start on a brand new design?

Open the Design Wizard. Pick the preset closest to your board, answer what you know, and read the report — it gives three candidate stackups with the reasoning, trace rules, a via schedule and thermal guidance, and exports to HTML or Markdown so it can live with the project.

Why doesn't the wizard give me a power plane?

Because a power plane is a poor reference and a GND plane is a good one. Every plane layer the wizard recommends is GND — a 4-layer board is always SIG / GND / GND / SIG — and power is routed on the signal layers as wide traces or local pours. A signal referenced to a power plane has to return through a decoupling capacitor every time it changes layers; one referenced to GND returns through a stitching via. On a standard 1.6 mm build the power/ground pair's capacitance is only about 20 pF/in², which the decoupling capacitors dwarf. See No power planes.

How much bulk capacitance does my regulator output need?

Open the Bulk Capacitance Wizard. It asks for the numbers from the regulator, load-IC and capacitor datasheets, tells you where each one is printed, and sizes the bulk from ripple, loop bandwidth, load-step droop, load-release overshoot and hold-up — whichever is largest governs — then converts the effective value to what you actually place after DC-bias derating.

Where in a datasheet do I find the minimum output capacitance?

In the regulator's Recommended Operating Conditions table (a C_OUT row), or in Application and Implementation → Detailed Design Procedure → Output capacitor selection, which often has a table of minimum C_OUT against output voltage. LDOs state it under Electrical Characteristics as the capacitance needed for stability, usually with an ESR range. It is normally an effective value — after DC-bias loss — so a 10 µF 0603 X5R at 3.3 V may not meet a 10 µF minimum.

Why does my via stub resonate lower than the quarter-wave formula says?

Because the planes the stub passes load it. The formula c/(4·L·√εr) is for a bare stub. In published and measured cases it read 21–47 % high, and up to 72 % high on dense GND-only stacks: a six-layer via's 1.7 mm stub at 17.35 GHz instead of 21.0, and a backplane's at 4.38 GHz instead of 5.75. Via Stub Impact shows the lowest the stub may resonate (quarter wave ÷ 1.75). The via network card in Via Properties solves the notch for your stack (full wave, within a few per cent of openEMS and a 3-D FEM) and brackets it with the network.

Do I need ground vias next to a signal via?

Yes, wherever the trace's reference changes from one plane to another. The return current then has to cross the cavity between those planes. With no ground via nearby, it spreads into the whole plane pair and takes signal power with it. The via network shows the difference: set its ground-via count to 0 and to 2, and compare |S21|. One or two ground vias within about 1 mm is the usual fix.

Should I give the wizard's stackup to my fab as-is?

Send it to them as a starting point, not a specification. Your fabricator has their own core and prepreg inventory, and the right move is to let them propose the nearest stackup they actually stock. Then bring their real dielectric heights back into the impedance tools and confirm the rules still hold.

Which tool do I use first for a high-speed design?

Roughly in this order: Design Wizard for the stackup, Trace Impedance and Differential Pair Designer for the geometry, Insertion Loss Budget to check the channel, Via Stub Impact to decide on back-drilling, and PCB Cost Estimator to price what you just specified.

Trust and limits

How do I know these numbers are right?

Every calculator names the standard or paper it implements, and the toolkit is checked against a reference implementation with over fifteen thousand parity assertions covering every calculator's numeric output. There are also published verification pages comparing results against independent third-party calculators. See Verification and limits.

What does "engineering-grade" mean?

Good enough to make a design decision with, not good enough to be a specification or a contract. The cost estimator is within about ±25 % of a real quote; the EMC tool is a screen, not a compliance prediction; the BGA standoff is a geometry estimate. Where a number is an estimate, the tool says so.

Can I use this for a safety-critical design?

Use it for exploration and sizing, then verify anything safety-related against the governing standard and your own qualification process. The creepage and clearance tool implements IEC 60664-1 correctly, but a compliance submission needs the standard itself and usually a test house — not a calculator's output.

Why do two tools give me different answers for the same thing?

Usually because they implement different standards, both correctly. The classic is trace current: IPC-2221 (1950s still-air data) and IPC-2152 (2009) differ in both directions. On an outer layer with no plane IPC-2152 allows about 25 % less current; on an inner layer, where IPC-2221 halves the current, IPC-2152 allows about 1.4–1.5× more. Check which methodology each tool is set to.

When should I distrust a result?

When the four analytic impedance estimates disagree with each other; when a diagnostic says you are outside a standard's validated range; when you may have given a tool bulk Dk where it wanted ε_eff; when a datasheet number is quoted at a different frequency than your design; and whenever a manufacturability limit matters and you have not asked your actual fab.

What can this toolkit not do?

It cannot read your design — no Gerber, ODB++, IPC-2581, netlist, CAD project, stackup file, IBIS model or Touchstone import. It cannot simulate a whole board or a channel end to end, produce a real eye diagram, or do thermal or mechanical FEA. It cannot check DRC or verify a layout, compare two revisions, or place an order with a fab. And it has no project model — inputs reset when you reopen a tool.

Can it check my layout or run DRC?

No. It tells you what the rules should be; it cannot see your board and cannot tell you whether the board follows them. Take the numbers into your CAD tool's design-rule editor.

Can it compare two revisions of a board?

No — there is no document model, no import and no diff. Each tool opens at its defaults and computes from what you type.

Can I import an IBIS or IBIS-AMI model?

No. There is no model import of any kind and no link training simulation. Driver and receiver behaviour enters the toolkit only as the numbers you type — rise time, data rate, jitter, loss budget.
