Getting started

Two ways to run the toolkit

In your browser. The web build runs the whole toolkit as WebAssembly — no install, no account, nothing uploaded. Everything computes on your own machine inside the browser tab. This is the fastest way to try a calculation.

On Windows, as a desktop app. The desktop build is the same application with one addition: it bundles the openEMS 3D field solver, so the Trace Impedance tool can run a real full-wave FDTD extraction instead of only the closed-form estimates. If you do not need 3D simulation, the browser build is functionally complete.

Both builds are free and carry a licence that permits commercial use.

The window

The layout is the same in both builds.

  • Left — the tool menu. Eight category groups plus the Design Wizard pinned at the top. The groups read top-to-bottom like a design flow: stackup → routing → vias → signal integrity → power integrity → RF → DFM → reference.
  • Top of the menu — the search box. Type any part of a tool's name, an alias, or a tag. Ctrl+P jumps straight to it from anywhere.
  • Centre — the active tool. Every tool page is laid out the same way: inputs on the left, outputs on the right, with a labelled diagram above the inputs so you can confirm you are describing the right geometry.
  • Bottom of every tool page — the help panel. "Help — what every input and output means" expands into a walkthrough of that specific tool. It is the same text as this manual's tool reference, kept next to the controls.
  • Bottom of the window — the status bar. Shows a one-line summary of the active tool.

On a narrow window the two columns stack and the menu collapses to an overlay; the hamburger button at the top left toggles it.

Finding the right tool

Search matches the tool's title, its aliases and its tags — so you do not have to know the toolkit's name for something. Typing Onderdonk finds Fusing Current, Zdiff finds the Differential Pair Designer, AWG finds Wire Ampacity, creepage finds Min Conductor Spacing, NSMD finds the BGA Pad Designer.

If you do not know what you are looking for at all, open the Design Wizard — it asks about the board you are building and points at the tools that matter for it.

How a tool page behaves

Everything is live. There is no Calculate button. Change an input and the outputs update as you type. The only exception is the 3D FDTD simulation on the impedance tool, which has an explicit Run 3D Simulation button because it takes tens of seconds to minutes.

Diagnostics appear below the outputs. Coloured banners carry three severities:

  • INFO — context worth knowing, not a problem.
  • WARN — the design will probably work but something is outside a normal range, or a manufacturability limit has been crossed.
  • ERROR — the inputs describe something that cannot be built, or a required value is missing or nonsensical.

A tool never silently clamps a bad input and shows you a plausible number. If the geometry does not work, it says so.

Nothing is saved automatically. Inputs reset to sensible defaults each time you open a tool. Tools that produce a document — the Design Wizard, the LC Matching Ladder — have explicit export buttons; see Files and exports.

Reading an output

Most outputs are shown in a monospaced font so columns line up, and most length outputs are given in both mil and mm, e.g. 9.45 mil (0.240 mm). Where a tool has a unit selector, that selector governs the whole page — see Units and conventions.

Numbers that are estimates rather than derivations are labelled as such — (est.) in a column header, or an explicit sentence in the help panel. When a tool has more than one methodology (IPC-2152 vs IPC-2221, Binomial vs Chebyshev, Cannonball-Huray vs Hammerstad-Jensen), a dropdown at the top of the inputs selects it, and the choice is reported with the result.

What the toolkit does not do

It does not phone home, does not require an account, and does not upload your design. The browser build in particular is entirely client-side — closing the tab discards everything.

It also does not read your CAD files. There is no Gerber, ODB++, IPC-2581 or netlist import; every input is typed. See Verification and limits for the full list of boundaries.
