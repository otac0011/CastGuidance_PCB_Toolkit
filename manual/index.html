CastGuidance PCB Toolkit — User Manual

Fifty PCB engineering calculators and wizards in one window: impedance, signal integrity, power integrity, RF matching, thermal, EMC, DFM and cost. Every formula is sourced to a published standard or paper, and every calculator is checked against a reference implementation before it ships.

This manual is the complete reference. If you have a specific question, start with the FAQ — it is written as questions, in the words people actually use.

What this toolkit is for

It is a design-time calculator set, not a simulator and not a quoting engine. It answers "what width should this trace be", "how much loss will this channel have", "is this pad buildable at my fab", "roughly what will this board cost" — quickly, with the standard behind each answer named, so you can make a decision and move on.

Where a number is an estimate rather than a derivation, the tool says so. Where the toolkit cannot answer a question at all, Verification and limits says that too.
