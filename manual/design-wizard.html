The PCB Design Wizard

A stepped questionnaire that turns a description of the board you are about to build into a starting stackup, a set of trace rules, a via schedule and thermal guidance. It is pinned at the top of the tool menu because it is the natural entry point for a new project.

Step 1 — pick a preset

Start from a preset that resembles your board — a USB-C charger, an RF prototype, a DDR4 motherboard — or choose Custom to answer everything from scratch. A preset only pre-fills the answers; every one of them is editable in step 2.

Step 2 — answer the questions

The wizard asks about the things that actually drive a stackup decision:

  • Board class and reliability target
  • Target signalling speeds and which interfaces are on the board
  • Intended manufacturer or fab class
  • Layer-count budget
  • Mechanical constraints — board thickness, size, connector heights
  • Whether there is RF content or it is purely digital
  • Target production volume
  • How sensitive the project is to bill-of-materials cost

Answer what you know and leave the rest at their preset values. The wizard is deliberately tolerant of partial information; it will tell you where an assumption drove a recommendation.

Step 3 — the report

The report summarises:

  • The top three recommended stackups with the rationale for each, so you can see why one was ranked above another rather than being handed a single answer.
  • Recommended trace and space rules consistent with that stackup and your fab class.
  • A suggested via schedule — which via types on which layer transitions.
  • Thermal guidance for the power content you described.

Differential pair widths

The wizard sizes each differential pair's legs for the bus's target Zdiff at the 2×-dielectric gap, by the Clemens Method (pre-solved 2D field solutions). Before 2026-10-20 it sized the legs for a single-ended target and quoted a closed-form Zdiff that reads 8–15 % high on surface pairs. The note on each pair rule says which model computed it.

No power planes

Every plane layer in a recommended stackup is GND. A 4-layer board is always SIG / GND / GND / SIG; 6- and 8-layer boards follow the same rule (SIG / GND / SIG / SIG / GND / SIG and SIG / GND / SIG / GND / GND / SIG / GND / SIG). Power is routed on the signal layers as wide traces or local pours, sized for the rail's current with Conductor Properties, and kept short from the regulator to the load.

The reasoning: a power plane used as a signal's reference forces every return current that changes layers to detour through a decoupling capacitor, while a second GND plane gives it a direct path through a stitching via. The "free" capacitance of a power/ground pair is small on a standard 1.6 mm build (the L2–L3 core is 1.26 mm, about 20 pF/in²), so it buys nothing the decoupling capacitors do not already supply. Stitch the GND planes together with vias at every layer change and along the board edge.

Export to HTML or Markdown saves the report so it can live with the project. This is the intended output: a document you attach to the design so that six months later the reasoning behind the stackup is still recoverable.

How to use the result

Treat the report as a starting point that survives contact with the fab, not as a specification. The recommended stackup is a well-reasoned default for the constraints you described; your fabricator will have their own preferred core and prepreg inventory, and the right move is to send them the report and let them propose the nearest stackup they actually stock.

Then take the numbers from their stackup back into the individual tools — Trace Impedance for the real dielectric heights, Differential Pair Designer for the pair geometry — to confirm the rules still hold on the stackup you can buy.

Bulk Capacitance Wizard

The second wizard in the group, listed under the PCB Design Wizard. It sizes the bulk / total capacitance of one power rail and, at every step, tells you which datasheet to open and where in it to look for each number — the section, table or graph, and what to use when the datasheet is silent.

The five steps

  1. The rail. What feeds it (buck, boost, LDO, or an off-board supply through a connector), its voltage, the dynamic tolerance left for transients, the largest load step and the maximum load. The tolerance comes from the load IC's Recommended Operating Conditions window minus the regulator's DC accuracy and ripple; the load step from the load's supply current or the vendor's power estimator.

  2. The regulator datasheet. For a switcher: minimum input voltage, switching frequency, inductor (Detailed Design Procedure → Inductor selection), loop crossover (Output capacitor selection or the Bode plot; f_sw/10 when not given) and ripple budget. For an LDO or off-board supply: the response time read off the Load Transient Response plot. Then the datasheet's minimum and maximum C_OUT, soft-start time and current limit.

  3. The load datasheets. The bulk and per-pin decoupling each load IC asks for on this rail (Power Supply Recommendations, Layout Guidelines, the Typical Application schematic, or for FPGAs and SoCs the separate hardware design guide).

  4. The capacitor. MLCC dielectric, case size and voltage rating — derated for DC bias and temperature with the same model as MLCC DC-Bias Derating — or polymer / electrolytic, plus tolerance, and the part's ESR (leave 0 for an MLCC to use the typical X5R/X7R law; a polymer part needs its datasheet's).

  5. Result. Every criterion as an effective capacitance, the one that governs, the nominal value and the number of parts to place, the maximum ESR, the input-capacitor size and RMS current, and a soft-start inrush check. Export it as text to keep with the design.

Upper limits are checked too: total capacitance above the regulator's maximum C_OUT, and soft-start charging current C·V_out/t_ss plus the load above the current limit, both raise a warning. Finish by checking the whole bank's Z(f) against the target impedance in the Cap Bank Analyzer.

ESR check and the hand-off to the Cap Bank Analyzer

The chosen part's ESR — the datasheet's, or for an MLCC the typical law 11 mΩ·(C/1 µF)^−0.36 fitted to Samsung's curves — is divided by the number of parts placed and compared with the ripple budget's maximum ESR: over it is a warning, over half of it a note. The law is an ESR at self-resonance; well below that the dielectric's loss raises it, so for a tight budget read the part's ESR-vs-frequency curve at f_sw.

Check in Cap Bank Analyzer on the result step opens the analyzer with the bulk parts at their effective value and ESR, each load's datasheet bulk, the loads' per-pin decoupling grouped by value (taken as 0402, 0603 above 1 µF — set the real cases), the target impedance ΔV/ΔI, and a sweep from the loop crossover (below it the regulator holds the rail) to 100 MHz, about where board decoupling hands over to the package. A banner there lists what it assumed.

What the wizard does not do

It does not generate CAD files, design rules files, or a stackup document in any fab's native format. It does not know your fabricator's inventory. And it does not replace a conversation with the fab — on any board where impedance control matters, that conversation happens anyway, and the report is what makes it a short one.
