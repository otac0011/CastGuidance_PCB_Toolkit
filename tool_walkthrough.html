Reference (12 tools)

Ohm's Law

No methodology dropdown — the four equations are linked, so any two known inputs give you the other two.

The page has four entry fields side-by-side; type whatever you know into any two of them and the other two compute automatically.

The Inputs are:

  • Voltage (V) — the potential across the element. Type your rail voltage here (1.8, 3.3, 5, 12 V, etc.).
  • Current (I) — the flow through the element. µA for signals, mA for IO, A for power.
  • Resistance (R) — the limit on current for the given voltage.
  • Power (P) — the heat dissipated.

The Outputs are the same fields, automatically filled. The tool also rounds R to the nearest E12 / E24 standard value so the answer is something you can actually order.

If the displayed power exceeds 50 % of a typical 0603 resistor's 100 mW rating, you should jump to a 1206 or 2010 package.

Conversion Calculator

Tabbed page — one tab per conversion domain.

The page is organised into tabs (Distance, Temperature, Power / dBm, Complex / rectangular ↔ polar). Each tab has the source value on the left and the destination on the right; type into either side and the other updates.

Common conversions: 1 mil = 0.0254 mm, 1 inch = 25.4 mm, 0 dBm = 1 mW = 224 mVrms @ 50 Ω, 10 dB = 10× power = 3.16× voltage.

SI Prefix Reference

Static reference table, no inputs.

The page is a single table covering every SI prefix from quecto (10⁻³⁰) to quetta (10³⁰) — name, symbol, power of ten, and an example. Use it when you can't remember whether "P" is peta or pico.

dBm Reference Chart

No methodology dropdown.

The Inputs section asks for:

  • System impedance — pick 50 Ω (RF lab default), 75 Ω (video / CATV), 600 Ω (legacy audio), or type a custom value.

The Outputs section is a pre-computed lookup table from −50 dBm to +40 dBm mapping each dBm level to mW and Vrms across your chosen impedance.

Mechanical Reference

Tabbed page with two reference tables, no calculations.

Tab one is Drill Sizes: every ANSI numbered drill (#80 through #1) and lettered drill (A through Z) with diameter in inch and mm. Tab two is Screw Threads: every UNC size (#00-90 up to 1/4-20) with major diameter, threads-per-inch, and tap-drill recommendation. Each tab has a live filter box — type "30" or "M3" to narrow the list.

Wire Ampacity / Resistance / Thermal

The page is organised into three input groups followed by three output groups.

Wire specification:

  • Gauge — pick from the full AWG dropdown (4/0 down to 40).
  • Conductor — solid or stranded copper, aluminum 1350, copper-clad aluminum, nichrome, constantan, manganin, or tinned/silver-plated copper.
  • Insulation — 20 classes from PVC 60 °C up to Kapton 260 °C, including the IEC 60317 magnet-wire enamel classes A through R.

Operating conditions:

  • Ambient temperature — the air around the wire (inside enclosures expect 20–40 °C hotter than the room).
  • Wire length — one-way; don't double for the return.
  • Current — set to 0 to just see the max ampacity; enter a real current to also see voltage drop, dissipation, and predicted wire temperature.
  • Source voltage — optional; enables voltage-drop-as-percentage output.
  • Frequency — optional; enables skin-depth + AC-resistance bump for RF use.

The Outputs include cross-section, diameter, R/m at ambient, total R at operating temp, max continuous ampacity (colour-coded against the insulation rating), Preece fusing current (catastrophic limit), wire temperature at your current, voltage drop with its % of source, power dissipated, skin depth, AC resistance, mass per metre.

Wire temperature at current is the most important number — if it's above the insulation's continuous rating you'll see an explicit "OVERHEAT" or "THERMAL RUNAWAY" diagnostic.

Reactance & LC Resonance

The Inputs are:

  • Frequency — where you want to evaluate the reactance.
  • Capacitance and Inductance — fill in either one, both, or neither depending on what you want.
  • Series R (for Q) — optional series resistance, used to compute the Q factor of an LC tank.

The Outputs are Xc (capacitive reactance), Xl (inductive reactance), f_resonant (where Xc = Xl), and the Quality factor.

A 100 nF cap presents only 16 mΩ at 100 MHz but 160 Ω at 10 kHz — same part, four orders of magnitude difference. The Q factor sets bandwidth: BW ≈ f₀ / Q.

LED Series Resistor

The Inputs section asks for:

  • Supply Vs — the rail you're driving from (3.3, 5, 12 V).
  • LED Vf — from the LED's datasheet. Typical: 1.8–2.0 V red, 2.8–3.4 V blue/white, 3.0–3.5 V power LEDs.
  • Desired If — typical 10–20 mA for indicators, 350 mA for 1 W power LEDs.
  • LED count (series) — multiplies Vf for strings.

The Outputs are the required exact R, both the nearest E12 and E24 standard values, the actual If when using the E24 part, the power dissipated in the resistor, and a recommended resistor package (0603/0805/1206/etc.) based on dissipation.

Voltage Divider

Four-corner solve mode: enter any two of Vin/Vout/R1/R2 and the other two are derived.

The Inputs allow you to fix any two of:

  • Vin — source voltage being divided.
  • Vout — target midpoint voltage.
  • R1 — top resistor (Vin to midpoint).
  • R2 — bottom resistor (midpoint to ground).

You'll see R_total (loading on the source), Current through the divider, and the power dissipated in each resistor. R1 and R2 outputs are snapped to E12 / E24 standard values.

For an ADC input, keep R1 ∥ R2 ≤ 10 kΩ so the source impedance doesn't load the sampling cap.

Series / Parallel R-L-C

The page is a table where each row is one element. Pick R, L, or C, then enter values one per row up to 8 elements. The Outputs are Series total (values add for R/L, reciprocals for C) and Parallel total (the opposite). Useful when you need an odd value (23.7 kΩ from your stock of standard parts) or want to parallel several resistors to spread power dissipation.

PPM Frequency Tolerance

Bidirectional — enter PPM or Δf, get the other.

  • Nominal frequency — what the crystal is supposed to oscillate at.
  • PPM — datasheet tolerance figure.
  • Frequency deviation — Δf, the actual Hz spread.

The Outputs include f_min and f_max (worst-case excursions), plus the reciprocal Δf/PPM number — type either side, read the other.

USB and CAN allow ±500 ppm; Ethernet 1G is ±100 ppm; GPS / disciplined OCXO is ±0.001 ppm. The datasheet "tolerance" combines initial frequency at 25 °C, temperature stability over operating range, and ageing per year — check the breakdown.

XTAL Load Capacitor

Sizes the two load caps for a Pierce oscillator around a parallel-resonant crystal.

  • Load capacitance CL — from the crystal datasheet (8, 10, 12, 18, 20, 32 pF are typical).
  • Stray capacitance — pin + PCB. Typical 8–14 pF total (5–6 pF per oscillator pin × 2 + 1–3 pF PCB).
  • C1 — optional, lets you specify C1 asymmetrically.

The Outputs are C1 and C2 (the two load caps, normally equal), plus a third line giving the symmetric "rule of thumb" value for reference.

Use NP0 / C0G caps for the load caps — X7R drifts several percent over temperature and detunes the crystal.

Core PCB (14 tools)

Conductor Impedance (analytic)

At the top of the page is the Methodology dropdown for picking the topology — Standard Microstrip, Embedded Microstrip, Symmetric / Asymmetric / Dual Stripline, Coplanar Waveguide (with and without backside ground). Each option swaps which input fields are visible.

Below that is the diagram, which changes based on the topology you've picked so you can confirm the geometry visually.

The Inputs section asks for:

  • Substrate εr — dielectric constant from the laminate datasheet.
  • Frequency — for the Kirschning-Jansen dispersion correction.
  • Width W — trace width.
  • Height H — distance from trace to ground reference plane.
  • Thickness T — copper thickness (0.5 oz = 0.7 mil, 1 oz = 1.4 mil, 2 oz = 2.8 mil).
  • H above / H below / Layer spacing — appear only for stripline / asymmetric stripline.
  • Cover thickness / Cover εr — appear for embedded microstrip.
  • Gap G — appears for coplanar topologies.
  • Target Z₀ — optional; entering this gives you a "Match to target" go/no-go and lets you tune W to hit a number.

The Outputs include Z₀ (characteristic impedance — the answer), ε_eff (the effective dielectric the line "sees"), Tpd (propagation delay in ps/in and ps/mm), and L and C per inch.

Match-to-target shows green if the line is within ±10 % of your target (the typical fab spec), amber within ±15 %, red beyond. ε_eff is between 1 (all air) and εr (all substrate); microstrip values typically run 60–70 % of εr.

Trace Impedance (openEMS 3D)

At the top of the page is the Methodology dropdown — currently the only entry is "3D FDTD (openEMS)" — and three large action buttons: Preview 3D Geometry, Analytic Fast Calc, and Run 3D Simulation.

The Inputs are similar to the analytic impedance tool — material (pick from the dropdown of bundled laminates), topology, geometry — but four extra sim-quality controls live in their own group: trace length, convergence target, mesh fineness, and worker thread count.

The Outputs panel shows the analytic answer side-by-side with the 3D FDTD result so you can see the discrepancy. Below the result panel is a status strip that tells you whether openEMS is installed and where.

Click Analytic Fast Calc first — it's instant and validates your inputs. Only run the full 3D simulation (30 s to several minutes) once you've confirmed the analytic answer is in the right ballpark.

Differential Pairs

At the top of the page is a topology selector (edge-coupled microstrip / stripline / coplanar, or broadside-coupled stripline). Below is the diagram.

The Inputs cover:

  • Substrate εr, Frequency, Width W, Thickness T, Height H — same as the single-ended impedance tool.
  • Spacing S — edge-to-edge spacing between the two traces.
  • H above / H below / Cover thickness / Cover εr — visible when the topology needs them.
  • Target Z_diff and Tolerance — drives the green/amber/red match indicator.
  • Signal Vpp / Rise time / Coupled length — used for the near-end crosstalk (NEXT) calculation.

The Outputs are Z_diff, Z_common, Z_odd, Z_even, Coupling Kb (and Coupling in dB), NEXT voltage, the saturation length Lsat, and the W/H / S/H ratios.

USB is 90 Ω, Ethernet / PCIe Gen3+ / HDMI are 100 Ω, CAN-FD is 120 Ω. Coupling above −10 dB means the traces interact strongly — good for EMC, but more sensitive to spacing tolerance.

Conductor Properties

At the top of the page is the Methodology dropdown — "IPC-2152 (2009, modern empirical fit)" or "IPC-2221 (1998, legacy K·ΔT^0.44·A^0.725)". IPC-2152 gives ampacities about 2× higher than IPC-2221 for the same temperature rise; modern designs use IPC-2152.

Below the dropdown is the diagram and then the Inputs:

  • Width W and Thickness T — trace cross-section.
  • Length L — for total resistance / voltage drop.
  • Current I — the steady-state current to carry.
  • ΔT — temperature rise above ambient you'll tolerate (10 °C is conservative, 30 °C aggressive).
  • Ambient T_a — base temperature.
  • Frequency — for skin depth.
  • Plane distance — distance to the nearest ground plane (IPC-2152 only).
  • Parallel count — for paralleled-trace power feeds.

The Outputs show Cross-section, the recommended Width for your current, DC resistance, Voltage drop, Power dissipated (and dBm), Skin depth, the ratio Skin / T, and ΔT virtual (the "virtual" temperature rise the formula was calibrated against).

Fusing Current (Onderdonk)

At the top is the Methodology dropdown — "Onderdonk 1928 (adiabatic, conservative)" or "Onderdonk × user multiplier (advisory)" if you want to apply a derating factor.

The Inputs are:

  • Width W and Thickness T — trace cross-section (or use AWG / mil dimensions).
  • Duration t — fault duration: 10 ms (fast fuse), 100 ms (slow fuse), 1 s (slow-blow).
  • Ambient T_a — board temp before the fault.
  • Multiplier — derating factor (only when using the advisory method).
  • Steady-state I_∞ — optional cross-check against the ampacity tool.

The Outputs are Fusing current at the chosen duration, the raw Onderdonk (raw) number for reference, and the cross-section in both mil² and circular mils.

A trace can survive 5–10× its steady-state ampacity for a few milliseconds. The fusing current is the current at which the trace reaches copper's melting point (1085 °C). Use it to size upstream fuses, or deliberately as a sacrificial fuse trace on cheap consumer boards.

Minimum Conductor Spacing

At the top is the Methodology dropdown — "IPC-2221C Table 6-1 (single 2-D lookup)" for board-level signal work, or "IEC 60664-1 Ed.3 (CTI + pollution + insulation)" for safety / mains compliance.

The Inputs are:

  • Voltage (peak) — DC working voltage or AC peak (230 Vac ≈ 325 V peak).
  • Environment class (IPC) or pollution degree + CTI grade + insulation type (IEC) — additional combos appear depending on the methodology you picked.

The Outputs are Minimum spacing (IPC), or separately Creepage (along the surface) and Clearance (through air) for the IEC method.

Creepage ≥ Clearance always. For mains-touching boards, milling a slot between the high-voltage and low-voltage sections gives effectively infinite creepage.

Wavelength

The Inputs are:

  • Frequency — what wavelength you want.
  • ε_eff — effective dielectric constant. Use 1 for vacuum / air, ≈0.65×Dk for microstrip, Dk for stripline.

The Outputs are Full λ, a list of Fractional λ (λ/2, λ/4, λ/8, λ/10, λ/20), and the Period in nanoseconds. λ/20 is the standard "lumped vs distributed" boundary — anything longer than that on the board needs controlled-impedance treatment.

εr Effective

At the top of the page there is no methodology dropdown — only one model (Hammerstad-Jensen static plus Kirschning-Jansen dispersion) is used.

Below the diagram, the Inputs are:

  • Width W — how wide the PCB trace is.
  • Height H — distance between the ground plane and the trace.
  • Substrate εr — the bulk dielectric constant of the laminate as found on its datasheet.
  • Frequency — the intended frequency of interest.

The Outputs show ε_eff (DC) (the low-frequency value, no dispersion correction), ε_eff (f) at your chosen frequency, and the W/H ratio.

A low W/H means more field lines are in the air, pulling ε_eff toward 1 (air). A high W/H means more field lines are inside the substrate, pulling ε_eff toward the bulk Dk value.

Bandwidth / Max Length

At the top is the Methodology dropdown — "IPC-2251 knee frequency (BW = 0.35 / Tr)", "Howard Johnson (BW = 0.5 / Tr, conservative)", or "Direct frequency entry" if you already know the frequency.

The Inputs are:

  • Rise time Tr — driver rise time (20–80 %).
  • Frequency — only used if you picked Direct entry.
  • ε_r_eff — for propagation velocity.

The Outputs are the signal's Bandwidth (knee frequency), the Wavelength λ at that frequency, and the Max conductor length before reflections matter (typically λ/6 of the knee).

Via Properties

The page starts with a Via type dropdown (Two-layer vs Multi-layer). Microvia analysis lives in its own dedicated tool — there's a pointer to it next to the dropdown.

The Inputs section asks for:

  • Hole Ø (finished) — plated drill diameter.
  • Plating thickness — typical 1 mil (25 µm).
  • Pad Ø D1 — capture pad outer diameter.
  • Antipad Ø D2 — clearance hole in surrounding plane layers.
  • Board thickness — top-to-bottom dielectric span.
  • Substrate εr — for capacitance and barrel Z₀.
  • ΔT (current) — allowed temperature rise for the ampacity calc.
  • Applied current — actual DC current for voltage-drop output.
  • Via count (array) — number of vias in parallel.

The Outputs cover Cross-section, DC resistance, Voltage drop, Inductance (Howard Johnson), Capacitance, Impedance (Z₀ of the barrel), Resonant freq, Step rise time, Aspect ratio, and the θ (thermal resistance) for one via and for the parallel array.

Microvia Analyzer (HDI)

Below the diagram (labelled with d / h / t / s and the WMI interface callout), the Inputs are split into three groups.

Microvia geometry:

  • Drill Ø (top of pocket) — laser-drilled hole diameter at the top. Typical 75–100 µm.
  • Depth — one dielectric layer, typically 50–100 µm.
  • Side-wall plating thickness — typical 8–15 µm.
  • Bottom-pocket plating — set to 0 for auto (70 % of side-wall, a typical conical-pocket ratio).
  • Capture pad Ø and Antipad Ø — same as a through-via.
  • Return-via spacing (s) — centre-to-centre to the nearest stitching via. Drives the inductance more than any other input.

Topology:

  • Connection target — Plane (lands on GND/PWR) or Trace (lands on a signal stub — emits an inductance-uncertainty warning).
  • Stack height — 1, 2, or higher.
  • Stack topology — Single, Staggered (preferred above 2), or Stacked (risky above 2).

Operating conditions: substrate εr, ambient, applied current, ΔT for ampacity, frequency (for skin effect), signal rise time (for the lumped-vs-distributed regime check).

The Outputs are split into Electrical, Regime, and Thermal/Ampacity groups, with the inductance using the return-path-aware Howard Johnson form and capacitance via the Gunston elliptic-coaxial formula. Reliability advisories (AR limit, WMI / first-reflow warning) appear in the diagnostics strip at the bottom.

Differential Via Stub

A simple back-of-envelope tool for the max acceptable stub length on a high-speed differential through-via. The Inputs are:

  • Baud rate (Gbps) — protocol data rate (or symbol rate for PAM4).
  • ε_r_eff — effective dielectric the via traverses.
  • Anisotropy factor — for substrates where z-axis Dk differs from x/y.

The Outputs are the Nyquist freq (baud / 2 for NRZ) and the Max stub length before the quarter-wave resonance lands inside the Nyquist band.

For a more detailed analysis with S21, eye-closure and budget consumption, use Via Stub Impact in the Signal Integrity category instead.

Planar Spiral Inductor

The page picks the shape (square, hexagonal, octagonal, circular) from a selector at the top of the inputs.

  • Turns N — total number of turns.
  • Conductor W — trace width.
  • Spacing S — gap between adjacent turns.
  • Outer Ø dout — outermost coil diameter.

The Outputs are Inductance (via Modified-Wheeler 1999), the Inner diameter (back-calculated), the Average diameter davg, the Fill factor ρ, and the shape constants K₁, K₂ used in the formula.

Embedded Resistor

Single-screen tool with three inputs:

  • Sheet R (Ω/□) — from the embedded-resistor foil vendor (typ. 25, 50, 100, 250, 1000 Ω/sq).
  • Length L and Width W — the rectangle you're patterning.

The Outputs are # of squares (L/W) and Total R. A 2:1 rectangle on a 50 Ω/sq foil makes a 100 Ω resistor; a 0.5:1 rectangle makes 25 Ω.

Signal Integrity (5 tools)

Via Stub Impact (S21, eye, budget)

At the top is a Protocol dropdown — pick PCIe Gen3/4/5/6, USB SuperSpeed, 25/50/100 GbE NRZ or PAM4, 112G PAM4, HBM, DDR5, MIPI C-PHY, CXL — and the data rate / modulation / rise time / IL-budget fields auto-populate from the spec.

Below the protocol picker is a Modulation dropdown (NRZ / PAM4 / PAM3) and a Differential checkbox.

The Channel inputs (auto-filled from preset but always editable):

  • Data rate — bits per second (NRZ) or symbol rate × 2 (PAM4).
  • Channel Z (per-leg) — usually 50 Ω.
  • IL budget @ Nyq — total channel budget per the protocol spec.
  • Rise time — 20–80 % edge rate from the driver datasheet.
  • FEC margin — protocol-specific forward-error-correction credit.

The Via geometry inputs are stub length, used via length, drill / pad / antipad diameters, plating, and (for differential) the via spacing. A Substrate dropdown picks Dk and tan δ from the bundled materials library.

The Outputs include a colour-coded Recommendation ("OK" / "Watch" / "Back-drill recommended" / "Back-drill required"), the Stub resonance frequency, Stub Q factor, Via barrel Z₀, Used via inductance, IL adder @ Nyquist and @ 2× Nyquist, Notch depth, Budget consumed (raw and after FEC), and a plotted |S21| curve.

Dielectric Dk/Df vs Frequency

At the top of the page is a Material dropdown — pick Megtron 6/7/8, Rogers RO4350B / RO4003C / RT-duroid, Isola family, AGC family, ITEQ, FR-4 generic, etc. — or "Custom" to enter your own datasheet point. There's also an Open Datasheet button.

The Inputs are:

  • Datasheet Dk — auto-filled by the dropdown.
  • Datasheet Df — auto-filled.
  • Datasheet frequency — usually 10 GHz; ITEQ IT-988GSE is at 28 GHz.
  • Target frequency — where you want to know Dk and Df.

The Outputs are Dk at target frequency, Df at target frequency, ΔDk vs datasheet, plus the fitted ε_∞ and Δε Djordjevic-Sarkar parameters that drive the wideband model.

Conductor Loss & Surface Roughness

At the top is the Methodology dropdown for the roughness model — Hammerstad-Jensen / Hemispherical / Cannonball-Huray (default).

The Inputs are:

  • Frequency — where you want the multiplier evaluated.
  • RMS roughness Δ — for Hammerstad and Hemispherical models.
  • Datasheet Rz — for Cannonball-Huray. Typical: STD 5.7 µm, RTF 4.4 µm, VLP 3.5 µm, HVLP 2.0 µm.

The Outputs are Loss multiplier K (vs smooth copper), Δ vs smooth in dB, and the Skin depth δ.

Channel Insertion Loss Budget

Single-page tool that tallies up dielectric, conductor, stub, and connector loss into one channel IL number.

  • Frequency — Nyquist of the link.
  • Trace length, width W, thickness T, Z₀, ε_eff, tan δ — trace parameters.
  • Copper Rz — foil roughness.
  • Via stub length — from the via-stub tool.
  • Connector loss — per-pair connector contribution in dB.

The Outputs include the Total IL and a per-component breakdown: Dielectric, Conductor, Via stub, Connector. It also reports α_d and α_c in dB/inch and the Roughness K multiplier.

Jitter Budget (Dual-Dirac)

  • Deterministic Dj (pp) — peak-to-peak deterministic jitter from clock recovery / ISI sources, in picoseconds.
  • Random Rj (rms) — Gaussian jitter standard deviation, also in ps.
  • Baud rate — line rate.

Also picks a target BER (1e-9, 1e-12, 1e-15) which sets the Q factor used in the dual-Dirac math.

The Outputs are Tj (peak-to-peak) — the total jitter at your target BER, UI (one bit), Tj as % of UI, and the Q factor applied.

Power Integrity (4 tools)

PDN Target & Plane Cap

Single-page tool combining target-impedance and plane-capacitance calculation.

  • Voltage rail — 0.85 V, 1.0 V (CPU core), 1.8 V, 3.3 V, 5 V, etc.
  • Ripple — allowed ripple as % of rail or as mV.
  • Max current — peak transient current.
  • Transient fraction — fraction of max-I that's the actual transient step.
  • Plane width, Plane length, Plane separation, Dielectric εr, Frequency — for the plane-capacitance computation.

The Outputs are Z_target (from V_ripple / I_transient), Plane capacitance (parallel-plate, plane area / spacing × Dk), Xc at frequency (plane impedance at that point), and the Xc / Z_target ratio — the frequency where the planes alone become insufficient and you need discrete decoupling caps.

MLCC DC-Bias Derating

  • Nominal C — sticker value on the part.
  • Rated voltage — the cap's max-rated voltage (10 V, 16 V, 25 V, etc.).
  • Applied voltage — the bias you'll actually run it at.
  • Operating temperature — for the thermal derating curve.

The Outputs are Effective C (what the cap actually delivers under bias), V_applied / V_rated (the % of rated voltage being used), and a Combined retention percentage broken into voltage and temperature retention factors.

A "10 µF 10 V X7R 0603" datasheet'd at 0 V often delivers 4 µF at 5 V bias — 40 % retention. The headroom matters: a 10 V part at 10 % bias keeps ~95 % of its capacitance, while a 6.3 V part at 80 % bias often drops to 20–30 %.

Mounting Inductance (L_mnt)

  • Via height (to plane) — depth from cap pad down to the reference plane.
  • Via diameter — typical 8–12 mil.
  • Pad length — capture pad dimension along the trace.
  • Pad-to-via separation — surface routing length between pad and via.

The Outputs include Total L_mnt (the parasitic loop inductance), broken into L_vias and L_pad/trace contributions, plus the Single-via inductance for reference.

Above ~100 MHz the mounting inductance dominates the cap's effective impedance — much more than the cap's own ESL. A 0.6 nH 0402 mounted with two through-board vias easily picks up 2 nH of mounting L, tripling the high-frequency impedance the rail sees.

PDN Cap Bank Analyzer (Z(f))

The page has a cap-bank table at the top — add caps from the MLCC library or by hand — followed by the sweep controls.

  • Sweep f_min and Sweep f_max — frequency range (typ. 10 kHz to 1 GHz).
  • Target Z — the target-impedance line drawn on the plot.

The Outputs are a |Z(f)| log-log plot with the target line overlaid, plus numerical readouts of the Worst-case |Z|, the NISM flatness Z_max / Z_min ratio, the count and locations of Anti-resonance peaks, and an overall pass/fail Result against the target.

RF / Microwave (5 tools)

Pi-Pad Attenuator

  • Attenuation — in dB (typical 3, 6, 10, 20, 30 dB).
  • Zin and Zout — source and load impedances. Equal for symmetric, unequal for matching pads.

The Outputs are the three exact resistor values (R series, R shunt (input), R shunt (output)) plus each one snapped to the nearest E24 standard value.

T-Pad Attenuator

Same Inputs as Pi-Pad — attenuation, Zin, Zout. The Outputs are R series (input, exact), R series (output, exact), R shunt (exact) plus E24-snapped versions of each. T-pads use the dual topology (series → shunt → series) — sometimes a cleaner layout fit than Pi.

L-Match (Impedance Matching)

  • Frequency — the design frequency.
  • Load R — real part of the load impedance.
  • Load X (j) — imaginary part (positive = inductive, negative = capacitive).
  • Source Z₀ — usually 50 Ω.

The Outputs are the Topology (which of the four valid L arrangements solves your match), the specific L and C values, the Loaded Q, and the Bandwidth (3 dB).

Quarter-Wave (λ/4) Impedance Match

At the top of the page is the Methodology dropdown — "Binomial (maximally flat, monotonic VSWR)" for clean in-band response, or "Chebyshev (equal-ripple, wider bandwidth)" for broader frequency coverage at the cost of in-band ripple.

  • Source Z and Load Z — must both be real.
  • Design frequency.
  • Substrate h and Copper t — for the microstrip width solver.
  • Sections spinner — number of cascaded λ/4 sections (1–9). More sections = wider bandwidth.
  • VSWR criterion — picks the bandwidth target (1.5:1, 2:1, 3:1).

The Outputs are Fractional bandwidth, the BW frequency range, the Total transformer length, plus a per-section table showing impedance / width / length for every section, and a plot of VSWR vs frequency.

Lumped LC Match (L / Pi / T)

At the top is the Methodology dropdown — "Lowpass (series L · shunt C)" or "Highpass (series C · shunt L)".

  • Source Z and Load Z.
  • Frequency — centre frequency.
  • Network topology (L / Pi / T) and target Q.

The Outputs are the component values, Loaded Q, 3 dB bandwidth, S11 @ f₀ (ideal), and S11 @ f₀ (snapped + parasitic) showing what the real implementation hits after E-series rounding and package parasitics.

Mechanical & DFM (4 tools)

Padstack

Tabbed page with four sub-tools: thru-hole pad, BGA land, pad clearance, and corner-to-corner pitch. Each tab has its own input set:

  • Thru-hole pad: Hole diameter, Min annular (ext), Min annular (int), Thermal isolation — gives the external/internal pad diameters and the thermal-relief geometry.
  • BGA land: Ball diameter, Pad pitch (c-c), Conductor width, Conductor spacing — gives the nominal land Ø with min/max tolerances.
  • Pad clearance: Hole diameter, Min annular ring — gives the max pad Ø and the achieved annular ring.
  • Corner-to-corner: Side a, Side b — diagonal pitch lookup.

Solder Paste Aperture (IPC-7525B)

  • Length and Width — for rectangular apertures.
  • Diameter — for circular apertures.
  • Stencil thickness — typical 4 mil (0.10 mm) for general work, 3 mil for fine-pitch.

The Outputs are Area ratio, Aspect ratio, Aperture area, and the IPC-7525B result (pass/fail/marginal). Both ratios should be ≥ 0.66 / ≥ 1.5 for clean paste release.

BGA Escape Routing

  • Ball pitch — typical 1.27 / 1.0 / 0.8 / 0.5 / 0.4 mm.
  • Pad diameter — BGA land size.
  • Clearance (pad → trace) — fab DRC minimum.
  • Trace width and Trace spacing — your design rules.

The Outputs are Channels per row (how many traces fit between adjacent balls), Free space between pads, Trace+space pitch, and Layers needed (how many signal layers it takes to fully break out the BGA).

Stackup Symmetry & Bow/Twist

The page is a stackup-editor table where each row is one layer with a copper-coverage percentage. The single non-table Input is:

  • Board length — for the IPC-6012E bow limit calculation.

The Outputs are Layer count, Symmetry score, Warp risk (low/medium/high colour-coded), and the IPC-6012E bow limit for your board size.

Thermal (2 tools)

Thermal Management

  • Ambient T_a — air temp around the part.
  • Power P — dissipation in watts.
  • θJA (°C/W) — junction-to-ambient from the package datasheet.
  • θJC (°C/W) — junction-to-case (for heatsinked use).
  • θCS (°C/W) — case-to-sink (thermal interface).
  • θSA (°C/W) — sink-to-ambient (heatsink datasheet).
  • Tj_max — datasheet maximum (typically 105 / 125 / 150 °C).

The Outputs are Tj (no heatsink), Tj (with heatsink), and the Margin to Tj_max in each case.

Thermal Via Array

  • Via count — number of vias under the exposed pad.
  • Hole diameter and Plating thickness — barrel geometry.
  • Via height (to plane) — depth from exposed pad to the conducting plane below.
  • Pad width and Pad length — IC exposed-pad footprint.
  • Via-fill k — thermal conductivity of any fill material (0 = air-filled).
  • Solder void fraction — typical 5–15 % for well-designed apertures.

The Outputs include the Single-via θ, the θ array (parallel + void), the θ spread (Lee plane), the Spreading fraction, and the Total θ. Total θ is what your thermal model needs.

Power Electronics (1 tool)

Buck / Boost Inductor Sizing

  • V_in and V_out — converter rail voltages.
  • Load current — steady-state output current.
  • Switching freq — fs (typ. 500 kHz – 2 MHz for silicon, > 3 MHz for GaN).
  • Inductor ripple — fraction of Iout (typ. 25–40 %).
  • Target ΔV_ripple — allowed output ripple voltage peak-to-peak.

The Outputs include Duty cycle, Required L (the inductor value to size), Inductor ripple ΔI_L, Peak current and RMS current (used to pick the saturation rating), Avg input current, plus the C_out min (output cap) and ESR max for the ripple-voltage budget.

EMC / EMI (1 tool)

Radiated Emissions — Small Loop

  • Frequency — the harmonic of interest (n × switching freq).
  • Loop length and Loop width — defines the loop area.
  • Peak loop current — for that harmonic.
  • Reporting distance — 3 m (FCC / CISPR) or 10 m for some standards.

The Outputs are the computed Loop area, the Predicted E-field in both µV/m and dBµV/m, the relevant Standard limit (FCC Class A / B, CISPR Class A / B), and the Margin to that limit with a colour-coded pass/fail Result.

High-Speed Digital (1 tool)

DDR Length Matching

The page has a stackup / standard picker at the top (DDR3 / DDR4 / DDR5 / LPDDR4 / LPDDR5) which auto-loads the JEDEC per-byte-lane tolerance.

The main Input is a per-signal length table — paste in or type the as-routed length of every DQ, DM, DQS, ADDR, CMD, and CK signal. The only standalone input is:

  • ε_eff (substrate) — for the propagation-velocity calculation.

The Outputs are the JEDEC tolerance for the chosen standard, the per-signal deviation from each byte's reference (DQS for DQ, CK for ADDR / CMD), the Worst-case skew, the Shortest and Longest signal, and the colour-coded Result (within / out of spec).

Wizard (1 tool)

PCB Design Wizard

Multi-step questionnaire — there's no single input page. Step 1 picks a preset (e.g. "USB-C charger", "RF prototype", "DDR4 motherboard") or "Custom". Step 2 asks targeted questions about your design (board class, target speeds, manufacturer, layer-count budget, mechanical constraints, RF or pure digital, target volume, BoM-cost sensitivity).

The final step is a Report page summarising the top-3 recommended stackups with rationale, recommended trace / space rules, suggested via schedule, and an export-to-HTML / Markdown button so you can save the report with the project.
